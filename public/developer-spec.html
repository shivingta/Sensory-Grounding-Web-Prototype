1. Flow & Clinical Somatic Architecture

The application implements a 5-stage somatic reset model engineered to down-regulate sympathetic nervous system distress through bilateral sensory grounding:

  1. Step 1 (Sight Awareness): 5 visual anchors with luminous optical cues.
  2. Step 2 (Physical Touch): 4 tactile anchors with body support cues.
  3. Step 3 (Ambient Sound): 3 auditory ambient layer cues.
  4. Step 4 (Subtle Scent): 2 olfactory respiratory prompts.
  5. Step 5 (Presence & Taste): 1 concentrated somatic palate anchor.

4. Key Architectural Implementations

A. Promise-Based Speech Sequencer (somaticNarrator.ts)

Standard browser window.speechSynthesis cancels active speech if a new utterance is queued carelessly. To eliminate audio cutoffs:

  • Chained Speech Execution (speakSequence): The step description finishes completely $\rightarrow$ utterance.onend fires $\rightarrow$ awaits a 650ms somatic breath pause $\rightarrow$ speaks Anchor 1.
  • Calibrated Voice Tones: Offers 3 profiles:
    • soft_meditative: Rate 0.80, Pitch 0.92, Volume 0.85 (Warm, whispered pacing).
    • gentle_calm: Rate 0.84, Pitch 0.96, Volume 0.90 (Unhurried cadence).
    • clear_grounded: Rate 0.88, Pitch 1.00, Volume 0.95 (Steady presence).

B. Tap & 1.2s Hold Deduplication (SomaticCore.tsx)

Users can complete anchors by either tapping or intentionally holding the center orb for 1.2 seconds without looking at the screen:

  • onPointerDown: Starts the hold timer and animates an SVG circular progress ring over 1200ms.
  • If held to 1200ms: Marks holdTriggeredRef.current = true and completes the anchor via 'hold'.
  • onPointerUp: Cleans up the timer and animation without triggering an extra tap.
  • onClick: Consumes the event only if holdTriggeredRef.current was false, ensuring exactly one anchor registers per click.

C. Procedural Sound Synthesizers (ambientAudio.ts)

No MP3 or WAV files are downloaded. The background ocean waves and rain are generated dynamically client-side using Web Audio API nodes (pink/white noise buffers modulated by low-frequency oscillators and resonant biquad filters).

5. Quickstart Guide for Developers

1. Clone and install dependencies:

git clone <repo-url>
cd <repo-folder>
npm install

2. Start local development server:

npm run dev

The applet runs at http://localhost:3000.

3. Lint and Build:

npm run lint    # Runs tsc --noEmit
npm run build   # Produces production bundle in /dist
